Recommended packages are waybar, kitty, rofi, hyprpaper, and neofetch. 
The wallpaper is 1d1309.png. Obviously change anything as you please but I think that color is most accurate the the terminal in White Knuckle.
Edit the waybar style.css file to direct to where you store the images for the bell and power symbol. Same deal for the paths to the neofetch ascii and hyprpaper wallpaper. 
Other images are included in this like the roach and hash symbols, you can use these as you please. 
I've also attached notification sounds from alerts in the game, use them if you want. Most sounds can be found on the wiki, if there's any sound from the game you want you can almost certainly find it there. 
The theme was built for my laptop so the only useful module other than the power button is the battery capacity in the middle. If you're on desktop obviously this isn't particularly useful, change anything however you want. 
The terminal font isn't quite perfect to White Knuckle. Pixelzone is more accurate but I haven't seen any monospace versions of it so it doesn't work with the terminal. I've chosen gohufont instead for this reason. If you do find/make a monospace version of pixelzone or a similar font do let me know, spent hours trying to make pixelzone into a mono font myself but it was a headache.
